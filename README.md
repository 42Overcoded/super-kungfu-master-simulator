# super-kungfu-master-simulator
A vr game about kungfu

## Description

As a kungfu master, you will fight against enemies in a virtual reality environment. Using your hands, you can send back the enemies' attacks, dodge their moves, and perform various kungfu techniques. The game is designed to be immersive and engaging, allowing you to experience the thrill of being a kungfu master.
